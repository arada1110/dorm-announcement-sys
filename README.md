# 📌 Dormitory Announcement System

## 🔍 About the Project

The **Dormitory Announcement System** is a web-based application designed to help dormitory administrators manage and distribute announcements efficiently to residents. The system centralizes communication through a single platform and integrates with LINE Official Account (LINE OA) to deliver important notifications directly to residents in real time.

Developed by **Arada Waenwong** as an academic project, this system covers the complete software development process, including system analysis, design, frontend and backend development, database management, and LINE Messaging API integration.

## ✨ Key Features

### 👨‍💼 Administrator

* Secure login and authentication
* Create, edit, and delete announcements
* Manage announcement categories
* View system overview through a dashboard
* Send announcements to residents via LINE OA

### 🏠 Resident

* Secure login and authentication
* View relevant announcements
* Receive notifications through LINE OA
* Stay updated with important dormitory news and information

## 🛠 Technologies Used

* **Frontend:** Vue.js
* **Backend:** NestJS
* **Database:** MySQL
* **Notification Service:** LINE Official Account (LINE OA)
* **Containerization:** Docker
* **Language:** TypeScript

## 🗄️ Core Data Structure

* User
* Role
* Announcement
* Category
* LineNotificationLog

## 🚀 Key Highlights

* Centralized announcement management platform
* Reduces communication gaps caused by traditional notice boards
* Real-time notification delivery through LINE OA
* Role-based access control for administrators and residents
* Scalable architecture that supports future system enhancements

## 🎯 Project Objectives

* Develop a user-friendly announcement management system for dormitories
* Improve communication efficiency between administrators and residents
* Integrate LINE Official Account (LINE OA) as a notification channel
* Apply software engineering and information system development practices in a real-world case study
